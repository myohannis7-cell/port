# Yohannis Mesfin - Professional Portfolio

A modern, professional portfolio website showcasing my work as a Full Stack Developer.

## Features

- Modern Design with animations and smooth transitions
- Fully Responsive for mobile, tablet, and desktop
- Contact Form with validation
- Project Showcase with live demos
- Skills Visualization with animated progress bars
- Professional Resume downloadable as PDF
- Testimonials Section for social proof
- SEO Optimized for search engines
- PWA Ready with manifest and favicon

## Getting Started

### View Portfolio
Simply open `index.html` in your web browser to view the portfolio.

### Generate Resume PDF

**IMPORTANT:** To make the Download Resume button work, you must first generate the PDF:

1. Double-click `open-resume.bat` (easiest method for Windows)
2. Follow the on-screen instructions
3. Press Ctrl+P and save as `Yohannis-Mesfin-Resume.pdf`

Or see `HOW-TO-GENERATE-PDF.md` for detailed step-by-step instructions.

## File Structure

- `index.html` - Main portfolio page
- `style.css` - Styles and animations
- `script.js` - Interactive features
- `resume.html` - Professional resume template (for PDF generation)
- `favicon.svg` - Site favicon
- `manifest.json` - PWA manifest
- `jovani.jpg` - Profile photo
- `open-resume.bat` - Quick PDF generation script (Windows)
- `generate-pdf.js` - PDF generation script (Node.js)
- `HOW-TO-GENERATE-PDF.md` - Detailed PDF generation guide

## Customization

### Update Your Information
1. Profile Image: Replace `jovani.jpg` with your photo
2. Contact Info: Update email, LinkedIn, GitHub links in `index.html`
3. Projects: Add your project links (replace # placeholders)
4. Resume: Edit `resume.html` to update your experience and skills
